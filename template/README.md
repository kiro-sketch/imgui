# Шаблон инжект-библиотеки с авто-определением рендера

Этот шаблон предоставляет основу для создания DLL-библиотеки, которая:
1. Автоматически определяет версию рендера (DirectX 9/10/11/12, OpenGL, Vulkan) приложения-хоста
2. Предоставляет унифицированное C API для рисования окон через C# библиотеку
3. Скрывает детали реализации рендера от C# кода

## Структура

```
template/
├── dllmain.cpp       # Точка входа DLL с авто-определением рендера
├── winmm.h           # Заголовочный файл с объявлениями
├── CMakeLists.txt    # Конфигурация сборки
└── README.md         # Этот файл
```

## Использование

1. Скопируйте содержимое папки `template` в свой проект
2. Реализуйте функцию `NsLoad()` для инициализации вашей логики
3. Добавьте файлы рендер-бэкендов из основного репозитория ImGui
4. Соберите библиотеку через CMake

## Интеграция с C#

Библиотека экспортирует C функции для рисования окон:

```csharp
// C# код не знает о конкретном рендере
ImGuiAPI.BeginWindow("My Window");
ImGuiAPI.Button("Click me");
ImGuiAPI.EndWindow();
```

## Сборка

```bash
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release
```

## Лицензия

Используется лицензия ImGui.
